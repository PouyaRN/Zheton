# 07 — Hide built-in categories

**What to build:** Built-in categories the user never uses can be hidden from pickers and filter chips, while transactions already classified into them keep their name. Hiding is a durable preference, not a deletion; built-in rows stay structural.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] A durable hidden-builtin list suppresses built-ins from category pickers, chips, and filters app-wide
- [ ] Existing transactions in a hidden built-in keep their classification and display name
- [ ] The categories management screen lets the user hide and unhide built-ins
