# 06 — Selection mode for search and bulk actions

**What to build:** The timeline supports multi-select: enter selection mode by long-pressing a row or tapping a select button in the search bar; rows show checkboxes; a batch action bar replaces the header while selecting; "select all matches" picks every row in the current search/filter result.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Long-press (and/or a select button) enters selection mode
- [ ] Checkboxes appear on timeline rows while in selection mode; the batch bar replaces header actions
- [ ] "Select all matches" selects the full filtered search result
- [ ] Selection exits cleanly (back / cancel), and selected transaction references are tracked
