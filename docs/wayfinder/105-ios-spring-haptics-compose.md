## Executive Summary

Fluid, organic responsiveness in Apple iOS (iOS 17/18 SwiftUI and UIKit) is defined by two tightly coupled physical domains:
1. **Continuous Second-Order Spring Dynamics:** Dynamic transitions are modeled on real damped harmonic oscillators parameterized by natural period ($T_n$ or `response`) and damping ratio ($\zeta$). They carry gesture velocity across boundaries without artificial interruption or linear easing discontinuities.
2. **Harmonic Voice-Coil Tactile Feedback (Taptic Engine):** Tactile events are not arbitrary vibrations; they are sharp, localized kinetic impulses generated by Linear Resonant Actuators (LRAs) tuned to specific transient frequencies (~150–240 Hz) and rapid decay profiles (<15ms).

This technical specification establishes the mathematical equivalence and implementation architecture for Android Jetpack Compose in `securityvisions/Dakh-o-kharj`:
- Converts Apple's `response` and `dampingRatio` parameters into Compose `stiffness` and `dampingRatio` values.
- Delivers exact spring tuning for the application's core gestures: **Sheet Pull-down & Settle**, **Card Stack Flick & Reorder**, and **Cupertino Tab Pill Sliding**.
- Establishes a 5-tier hardware fallback matrix mapping `UIImpactFeedbackGenerator` (`.light`, `.medium`, `.heavy`, `.rigid`, `.soft`), `UINotificationFeedbackGenerator` (`.success`, `.warning`, `.error`), and `UISelectionFeedbackGenerator` to Android 14+ (`HapticFeedbackConstants`), Android 12+ (`VibrationEffect.Composition` primitives), Android 10+ (Predefined effects), Android 8+ (`VibrationEffect` Waveforms), and legacy API 24-27.

# Part 1: Spring Physics Equivalence (SwiftUI/UIKit $\to$ Jetpack Compose)

```

             Displacement x(t)
         ◄───────────────────────►
        ┌─────────────────────────┐
        │       Mass m = 1.0      │ ───► Velocity v(t) = dx/dt
        └─────────────────────────┘
          ▲                     ▲
          │ k (Stiffness)       │ c (Damping Coefficient)
          ▼                     ▼
        ┌───────┐             ┌───────┐
        │Spring │             │Dashpot│
        └───────┘             └───────┘
```

## 1. Mathematical Derivation

Both iOS (`CASpringAnimation`, SwiftUI `Animation.spring`) and Android Jetpack Compose (`androidx.compose.animation.core.spring`) solve the second-order homogeneous ordinary differential equation for a damped harmonic oscillator:

$$m \frac{d^2x}{dt^2} + c \frac{dx}{dt} + k x = 0$$

Normalizing with mass $m = 1.0$:

$$\ddot{x} + 2\zeta\omega_n \dot{x} + \omega_n^2 x = 0$$

Where:
- $\omega_n = \sqrt{k}$ is the undamped angular natural frequency (radians per second).
- $k$ is the spring stiffness constant (`stiffness` in Compose).
- $c = 2\zeta\omega_n$ is the viscous damping coefficient.
- $\zeta = \frac{c}{2\sqrt{k}}$ is the dimensionless damping ratio (`dampingRatio` in Compose).

### Apple SwiftUI Parameterization
Apple SwiftUI specifies springs using:
1. **`response` ($T_n$):** The period of the undamped system in seconds:
   $$T_n = \frac{2\pi}{\omega_n} \iff \omega_n = \frac{2\pi}{T_n}$$
2. **`dampingRatio` ($\zeta$):**
   - $\zeta = 1.0$: Critically damped (snaps to equilibrium with zero overshoot).
   - $\zeta < 1.0$: Underdamped (oscillates around target; smaller values create more bounce).
   - $\zeta > 1.0$: Overdamped (sluggish, exponential approach without oscillation).

### Translation Formulas to Jetpack Compose

To replicate an Apple spring specified with $(T_n, \zeta)$ in Jetpack Compose:

$$\text{stiffness} = \omega_n^2 = \left(\frac{2\pi}{T_n}\right)^2 = \frac{4\pi^2}{T_n^2}$$

$$\text{dampingRatio} = \zeta$$

### Inversion (Compose to Apple SwiftUI)

Given Compose `stiffness` $k$:

$$T_n = \frac{2\pi}{\sqrt{k}}$$

### 3.1 Sheet Pull-Down, Settle & Dismiss (`BankSheet`, `CardEditorSheet`)
- **Problem:** Naive Compose bottom sheets bounce off the top anchor when flung upward or oscillate excessively when pulled down and released.
- **Physics Spec:**
  - **Drag Tracking:** Follow finger 1:1; above sheet max height, apply rubber-banding:
    $$\Delta x_{\text{visual}} = \Delta x_{\text{drag}} \times \left(1 - \frac{1}{\frac{0.55 \cdot \Delta x_{\text{drag}}}{\text{Height}} + 1}\right)$$
  - **Detent Settle (Snap to Expanded / Half-Expanded):**
    - $T_n = 0.42\text{ s}, \zeta = 0.84$
    - **Compose Parameters:** `stiffness = 240f`, `dampingRatio = 0.84f`
    - *Feel:* Settles promptly with a soft, organic deceleration and negligible overshoot (<1.5dp).
  - **Flick Dismiss (Snap to Bottom / Exit):**
    - $T_n = 0.30\text{ s}, \zeta = 1.0f$
    - **Compose Parameters:** `stiffness = 440f`, `dampingRatio = Spring.DampingRatioNoBouncy (1.0f)`
    - *Feel:* Zero rebound; travels straight off the canvas.
  - **Velocity Transfer:** Preserve gesture velocity via `Animatable.animateTo(targetValue, initialVelocity = flingVelocity)`.

### 3.2 Card Flick & Fan-out (`AppleWalletDeck`, `BankCard3D`)
- **Problem:** Cards in a wallet stack feel cardboard-stiff when linear or rubbery when using `DampingRatioHighBouncy`.
- **Physics Spec:**
  - **Stack Expansion / Fan-out:**
    - $T_n = 0.38\text{ s}, \zeta = 0.78$
    - **Compose Parameters:** `stiffness = 280f`, `dampingRatio = 0.78f`
    - *Feel:* Satisfying physical card spread with one gentle settle cycle.
  - **Stack Collapse / Return to Deck:**
    - $T_n = 0.32\text{ s}, \zeta = 0.88$
    - **Compose Parameters:** `stiffness = 380f`, `dampingRatio = 0.88f`
  - **3D Specular Tilt Recovery (BankCard3D):**
    - When user releases gyro/drag tilt:
    - **Compose Parameters:** `stiffness = 650f`, `dampingRatio = 0.76f`
    - *Feel:* Rapid rotational snap back to flat horizon with subtle kinetic recovery.

### 3.3 Tab Pill Sliding (`TabBar` Cupertino Island)
- **Problem:** The sliding indicator pill in standard Compose either lags behind tap events or overshoots past adjacent tabs.
- **Physics Spec:**
  - $T_n = 0.28\text{ s}, \zeta = 0.94$
  - **Compose Parameters:** `stiffness = 520f`, `dampingRatio = 0.94f`
  - *Feel:* Swift, mechanical snap. Never visibly crosses into non-selected tab territory.
  - **Horizontal Width Stretch:** During high-velocity tab jumps ($|\Delta x| > 80\text{dp}$), pill momentarily scales width by $1.06\times$, relaxing back to $1.0\times$ at target.

### 3.4 Micro-scale Button Interaction (Scale on Touch)
- **Press In (Scale to 0.96x):**
  - $T_n = 0.10\text{ s}, \zeta = 1.0f \implies$ `stiffness = 3900f`, `dampingRatio = 1.0f`
- **Release Out (Rebound to 1.0x):**
  - $T_n = 0.24\text{ s}, \zeta = 0.65 \implies$ `stiffness = 680f`, `dampingRatio = 0.65f`

## 1. Hardware Architecture Differences

1. **Apple Taptic Engine:** Custom high-mass Linear Resonant Actuator (LRA) driven by a dedicated DSP. Starts and brakes in under $5\text{ ms}$. Operates across an intentional tactile frequency range ($150\text{ Hz} - 240\text{ Hz}$).
2. **Android Modern Flagships (Pixel 6-9, Galaxy S22-25, Xiaomi/OnePlus flagships):** Equipped with high-grade X-axis LRAs capable of hardware primitive compositions (`PRIMITIVE_CLICK`, `PRIMITIVE_TICK`, `PRIMITIVE_THUD`).
3. **Budget / Mid-tier Android Devices:** Often equipped with Z-axis LRAs or legacy Eccentric Rotating Mass (ERM) motors. ERM motors have high inertial spin-up latency ($30-50\text{ ms}$) and cannot render micro-clicks cleanly.
4. **Engineering Imperative:** The engine must query hardware primitive support dynamically via `Vibrator.areAllPrimitivesSupported(...)` and fall back seamlessly down through five API tiers without throwing exceptions or blocking UI threads.

## 2. Studio Tactile Haptic Engine (`FintechHaptics.kt`)

```kotlin
package com.doxigo.muchtoman.ui.haptics

import android.annotation.SuppressLint
import android.content.Context
import android.os.Build
import android.os.SystemClock
import android.os.VibrationAttributes
import android.os.VibrationEffect
import android.os.Vibrator
import android.os.VibratorManager
import android.provider.Settings
import android.view.HapticFeedbackConstants
import android.view.View
import androidx.compose.runtime.Composable
import androidx.compose.runtime.ProvidableCompositionLocal
import androidx.compose.runtime.remember
import androidx.compose.runtime.staticCompositionLocalOf
import androidx.compose.ui.platform.LocalContext
import androidx.compose.ui.platform.LocalView

/**
 * Complete tactile haptic engine for ChandToman / Dakh-o-kharj.
 * Maps 1:1 to Apple iOS UIKit & CoreHaptics Taptic Engine paradigms.
 */
interface FintechHaptics {

    // --- UIImpactFeedbackGenerator ---
    fun impactLight()
    fun impactMedium()
    fun impactHeavy()
    fun impactRigid()
    fun impactSoft()

    // --- UINotificationFeedbackGenerator ---
    fun notificationSuccess()
    fun notificationWarning()
    fun notificationError()

    // --- UISelectionFeedbackGenerator ---
    fun selectionChanged()

    // --- Backward-Compatible Aliases ---
    fun tick() = selectionChanged()
    fun click() = impactMedium()
    fun heavyClick() = impactHeavy()
    fun doubleTap() = notificationSuccess()
}

/**
 * 5-tier high performance haptics implementation supporting Android API 24 through 34+.
 */
class AndroidFintechHaptics(
    private val context: Context,
    private val view: View?,
) : FintechHaptics {

    private val vibrator: Vibrator? = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
        val manager = context.getSystemService(Context.VIBRATOR_MANAGER_SERVICE) as? VibratorManager
        manager?.defaultVibrator
    } else {
        @Suppress("DEPRECATION")
        context.getSystemService(Context.VIBRATOR_SERVICE) as? Vibrator
    }

    // Pre-calculated waveforms for API 26-28 to ensure zero allocation in gesture loops
    private val successWaveform: VibrationEffect? = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
        VibrationEffect.createWaveform(
            longArrayOf(0L, 12L, 60L, 18L),
            intArrayOf(0, 90, 0, 220),
            -1,
        )
    } else null

    private val warningWaveform: VibrationEffect? = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
        VibrationEffect.createWaveform(
            longArrayOf(0L, 25L, 90L, 35L),
            intArrayOf(0, 160, 0, 240),
            -1,
        )
    } else null

    private val errorWaveform: VibrationEffect? = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
        VibrationEffect.createWaveform(
            longArrayOf(0L, 15L, 35L, 15L, 35L, 15L, 35L, 20L),
            intArrayOf(0, 220, 0, 190, 0, 160, 0, 240),
            -1,
        )
    } else null

    private val softWaveform: VibrationEffect? = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
        VibrationEffect.createWaveform(
            longArrayOf(0L, 10L, 15L, 8L),
            intArrayOf(0, 45, 90, 45),
            -1,
        )
    } else null

    // Debounce tracker for continuous selection scrubbers (20ms throttle)
    private var lastSelectionTimestamp: Long = 0L

    private fun isHapticsEnabled(): Boolean {
        return try {
            Settings.System.getInt(
                context.contentResolver,
                Settings.System.HAPTIC_FEEDBACK_ENABLED,
                1,
            ) != 0
        } catch (_: Throwable) {
            true
        }
    }

    // ========================================================================
    // UIImpactFeedbackGenerator Mappings
    // ========================================================================

    @SuppressLint("MissingPermission")
    override fun impactLight() {
        if (!isHapticsEnabled()) return
        try {
            // API 31+ Primitive Click at light scale
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S && vibrator != null &&
                vibrator.areAllPrimitivesSupported(VibrationEffect.Composition.PRIMITIVE_CLICK)
            ) {
                vibrator.vibrate(
                    VibrationEffect.startComposition()
                        .addPrimitive(VibrationEffect.Composition.PRIMITIVE_CLICK, 0.45f)
                        .compose(),
                    VibrationAttributes.createForUsage(VibrationAttributes.USAGE_TOUCH),
                )
                return
            }

            // API 29-30 Predefined
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q && vibrator != null) {
                vibrator.vibrate(VibrationEffect.createPredefined(VibrationEffect.EFFECT_CLICK))
                return
            }

            // API 26-28 OneShot
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O && vibrator != null) {
                vibrator.vibrate(VibrationEffect.createOneShot(8L, 70))
                return
            }

            // Legacy Fallback
            view?.performHapticFeedback(
                HapticFeedbackConstants.KEYBOARD_TAP,
                HapticFeedbackConstants.FLAG_IGNORE_VIEW_SETTING,
            )
        } catch (_: Throwable) {}
    }

    @SuppressLint("MissingPermission")
    override fun impactMedium() {
        if (!isHapticsEnabled()) return
        try {
            // API 31+ Primitive Click at firm scale
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S && vibrator != null &&
                vibrator.areAllPrimitivesSupported(VibrationEffect.Composition.PRIMITIVE_CLICK)
            ) {
```
